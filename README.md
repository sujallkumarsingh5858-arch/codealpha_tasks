# LearnEase — Task 1: Wireframing & Low-Fidelity Design

**Internship:** CodeAlpha UI/UX Design Internship  
**Project:** LearnEase — Online Learning Platform  
**Task:** Task 1 — Wireframing & Low-Fidelity Design

## Project overview
LearnEase is a proposed online learning platform for students to discover courses, continue learning, and track progress.

## Objective
Create low-fidelity desktop website wireframes that establish page structure, navigation, content hierarchy, and core interface sections before high-fidelity visual design.

## Deliverables
### 1. Home Dashboard
Shows learning progress, a continue-learning card, popular courses, and upcoming lessons.
File: `01_Home_Dashboard_Wireframe.png`

### 2. Course Catalogue
Shows course search, category filters, sorting, course cards, and pagination.
File: `02_Course_Catalogue_Wireframe.png`

### 3. Course Details
Shows course information, preview area, enrollment details, learning outcomes, and curriculum.
File: `03_Course_Details_Wireframe.png`

## Design approach
- Desktop-first layout for laptop screens.
- Grayscale wireframe styling to emphasize structure and usability.
- Shared top navigation and sidebar across screens.
- Clear content hierarchy and consistent alignment.
- Placeholder blocks for image and video content.

## Tool used
- Figma (with AI-assisted wireframe generation)
