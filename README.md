---

Project Overview

LearnEase is a proposed online learning platform designed to help students discover courses, continue learning, and track their progress through a clear, consistent desktop interface.

This project focuses on the UI/UX design process, starting with low-fidelity wireframes, progressing to high-fidelity UI designs, and concluding with an interactive clickable prototype.

Project Goals

- Create clear and user-friendly website layouts.
- Establish page structure and content hierarchy through low-fidelity wireframes.
- Transform wireframes into polished high-fidelity UI designs.
- Maintain consistent navigation, typography, colours, and components.
- Create an interactive prototype to demonstrate user navigation and screen-to-screen interactions.

Tasks and Deliverables

Task 1 — Wireframing & Low-Fidelity Design

Created three grayscale desktop wireframes to establish the structure, layout, and navigation of the LearnEase platform.

Screens designed:

- Home Dashboard
- Course Catalogue
- Course Details

Screens designed:

Folder: "Task-2-High-Fidelity/"

Task 4 — Interactive Prototyping

Created a clickable Figma prototype by connecting the three high-fidelity LearnEase screens to demonstrate user navigation and interaction flow.

Main prototype screens:

- Home Dashboard
- Course Catalogue
- Course Details

Prototype interactions:

- Home Dashboard → Course Catalogue
- Home Dashboard → Course Details
- Course Catalogue → Course Details
- Course Details → Course Catalogue
- Navigation back to Home Dashboard

The prototype was tested in Figma Present mode to demonstrate the navigation between screens.
