# LearnEase — Task 2: High-Fidelity UI Design

**Internship:** CodeAlpha UI/UX Design Internship  
**Project:** LearnEase — Online Learning Platform  
**Task:** Task 2 — High-Fidelity UI Design

## Project Overview

LearnEase is a proposed online learning platform that helps students discover courses, continue learning, and track their progress.

## Objective

Transform the low-fidelity wireframes from Task 1 into polished high-fidelity desktop UI designs with consistent colors, typography, imagery, and interface components.

## Deliverables

### 1. Home Dashboard

Displays learning statistics, Continue Learning, popular courses, progress indicators, and upcoming lessons.

**File:** `01_Home_Dashboard_HighFidelity.png`

### 2. Course Catalogue

Displays course search, category filters, sorting controls, course cards, instructor information, ratings, and durations.

**File:** `02_Course_Catalogue_HighFidelity.png`

### 3. Course Details

Displays course information, preview media, instructor details, enrollment options, learning outcomes, curriculum, and reviews.

**File:** `03_Course_Details_HighFidelity.png`

## Design Approach

- Desktop-first layouts.
- Consistent navigation across all three screens.
- Indigo accents, light backgrounds, and white cards.
- Clear visual hierarchy and readable typography.
- High-fidelity designs based on the Task 1 wireframes.

## Tools Used

- **Google Stitch:** AI-assisted UI generation.
- **Figma:** Importing, organizing, and editing the designs.
