1. Project Overview

LearnEase is an online learning platform concept designed to help learners explore courses, view course information, and continue their learning journey.

For Task 4, I created a clickable Figma prototype by connecting the high-fidelity screens developed for the LearnEase project.

The main objective was to demonstrate screen navigation, interactive elements, and the overall user journey.

2. Main Screens

The prototype includes three main screens:

01. Home Dashboard

Provides learners with an overview of their learning activities, course progress, and quick access to courses.

02. Course Catalogue

Allows users to browse and explore available courses across different categories.

03. Course Details

Displays information about a selected course, including course content and enrolment options.

3. Prototype Interactions

The following navigation interactions were implemented:

Starting Screen| Interaction| Destination
Home Dashboard| Explore Courses| Course Catalogue
Home Dashboard| Continue / Resume Learning| Course Details
Course Catalogue| Select Course / View Course| Course Details
Course Details| Back to Courses| Course Catalogue
Other Screens| Home Navigation| Home Dashboard

4. User Flow

The main user journey is:

Home Dashboard → Course Catalogue → Course Details

Users can also navigate directly from the Home Dashboard to Course Details and return to the previous sections using the available navigation elements.
